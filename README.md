# Battle Connect 4

A browser-based, stream-friendly two-player Connect Four game. No TikTok connection is required for this first version.

## Play locally
Open `index.html` in a modern browser.

## Publish with GitHub Pages
1. Open the repository **Settings**.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then save.
5. Wait for GitHub Pages to publish the site. The URL will appear in the Pages section.

## Features
- Vertical, stream-friendly layout
- Editable player/team names and round scores
- Alternating turns with legal column drops
- Automatic four-in-a-row and draw detection
- Winning line highlight
- Winner starts the next round and chooses the opening column
- Undo last move, manually switch the next turn, or reset scores

TikTok LIVE integration is intentionally not included yet; the game can be extended later.
